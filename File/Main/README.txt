# Portfolio Redesign

## File utama
- `index.html` — halaman beranda.
- `about.html` — profil, pendidikan, pengalaman, dan skill.
- `portofolio.html` — daftar laporan/proyek dengan filter kategori.
- `contact.html` — halaman kontak.
- `styles.css` — stylesheet bersama untuk semua halaman.
- `report.css` — lapisan gaya khusus untuk halaman laporan praktikum.
- `interactions.js` — pencarian portofolio, animasi, pratinjau gambar, dan tombol kembali ke atas.

## Template laporan
- `LangkahAppMobile1.html` — tampilan ulang laporan praktikum Flutter yang sudah ada.
- `laprakPweb5.html` — template laporan praktikum web yang dapat disalin untuk laporan baru.

## Palet warna
- Turquoise: `#00BCC8`
- Lime: `#D0FF00`
- Teks utama: `#14282C`
- Latar: `#F8FBFA`
- Permukaan kartu: `#FFFFFF`

## Catatan penggunaan
1. Simpan semua file HTML dan `styles.css` dalam folder yang sama.
2. Pertahankan folder/gambar aset yang dirujuk oleh laporan lama.
3. Pada template PWEB, ganti judul, deskripsi, kode, dan nama screenshot sesuai praktikum.
4. Form kontak menggunakan `mailto:` sebagai contoh. Isi alamat email tujuan pada `action` sebelum dipakai.
5. Bootstrap 5.3.3, Bootstrap Icons, dan Google Fonts dimuat melalui CDN sehingga memerlukan koneksi internet.
